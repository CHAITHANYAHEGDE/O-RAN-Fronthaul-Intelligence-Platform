# API Reference

## POST /upload

Uploads throughput and packet statistics datasets.

### Response

* Upload status
* Processed file summary
* Topology information

---

## GET /topology

Returns discovered network topology.

### Response

* Link identifiers
* Cell relationships
* Connectivity structure

---

## GET /capacity

Returns estimated fronthaul capacity recommendations.

### Response

* Capacity estimates
* Utilization metrics
* Optimization recommendations

---

## GET /

Health check endpoint.

### Response

Platform status information.
